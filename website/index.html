Une API Intuitive & Expressive

from ffbb_data_client import FFBBDataClient

client = FFBBDataClient.create()

# Recherche globale multi-index (organismes, compétitions, salles...)
results = client.multi_search("Clermont")

for group in results or []:
    print(f"Index {group.index_uid} : {len(group.hits)} résultats trouvés")

# Recherche géographique de clubs dans un rayon de 25 km
clubs = client.search_organismes_by_geo(lat=45.7772, lng=3.0870, radius_km=25)

import asyncio
from ffbb_data_client import FFBBDataClient

async def main():
    client = FFBBDataClient.create()

    # Appels concurrents ultra-rapides avec asyncio.gather
    saisons, lives = await asyncio.gather(
        client.get_saisons_async(active_only=True),
        client.get_lives_async()
    )

    print(f"Saison active : {saisons[0].libelle}")
    print(f"Matchs en direct : {len(lives)}")

asyncio.run(main())

C'est le SDK Python moderne, asynchrone et typé (Pydantic v2) pour interagir avec les APIs publiques de la Fédération Française de BasketBall (FFBB). Il permet de récupérer facilement calendriers, classements, statistiques, scores live et fiches de clubs.

ffbb-data-client est la bibliothèque Python (SDK) d'accès aux données. FFBB MCP Server est le serveur de contexte IA (Model Context Protocol) qui expose ces données sous forme d'outils et de ressources pour les LLM (Claude, Copilot, Cursor).
