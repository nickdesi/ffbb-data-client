COMPARATIF & MIGRATION

Pourquoi choisir ffbb-data-client ?

Le SDK moderne conçu pour remplacer définitivement les anciens packages non maintenus (ffbb-api-client, ffbb-api-client-v2).

Fonctionnalité ffbb-data-client (Recommandé) Anciens wrappers (v1, v2)
⚡ Support Asynchrone (async/await) ✅ Oui (httpx & asyncio natif) ❌ Non (synchrone bloquant)
🛡️ Modèles Typés & Validation ✅ Pydantic v2 complet ❌ Dictionnaires bruts non typés
🔴 Scores en Direct (Lives du week-end) ✅ Oui (Endpoint get_lives) ❌ Non disponible
🔍 Recherche Meilisearch Multi-Index ✅ 9 index officiels instantanés ❌ Scraping ou recherche lente
💾 Cache HTTP Intelligent ✅ Hishel SQLite configurable ❌ Aucun cache ou basique
🤖 Connecteur IA / MCP Server ✅ Compatible MCP natif ❌ Incompatible

FAQ API FFBB

Questions fréquentes sur l'API FFBB

Tout ce que vous devez savoir pour démarrer et utiliser les données officielles de la Fédération.

Comment utiliser l'API FFBB en Python ? +

Il vous suffit d'installer le paquet via pip install ffbb-data-client. Vous pouvez alors instancier le client avec FFBBDataClient.create() sans aucune clé d'API requise pour interroger clubs, poules, classements et scores live.

Quelle différence avec ffbb-api-client ou ffbb-api-client-v2 ? +

Les anciennes bibliothèques ne sont plus maintenues et utilisent d'anciennes structures bloquantes. ffbb-data-client est la solution de référence 2026 : asynchrone, modèles Pydantic v2 validés, support des scores en direct et intégration avec les agents IA via MCP.

Puis-je l'utiliser pour le site internet de mon club ? +

Oui, absolument ! C'est l'un des usages principaux : alimenter les pages résultats, classements et calendriers de votre club ou de votre comité en temps réel sans aucune saisie manuelle.

Comment poser des questions en langage naturel via l'IA ? +

Grâce au FFBB MCP Server (endpoint https://ffbb.desimone.fr/mcp), vous pouvez connecter directement votre assistant IA (Claude, Copilot, Cursor) pour obtenir des réponses immédiates sur n'importe quelle équipe ou compétition.
