import asyncio
from ffbb_data_client import FFBBDataClient

async def main():
    client = FFBBDataClient.create()

    # Appels concurrents non-bloquants
    saisons, lives = await asyncio.gather(
        client.get_saisons_async(active_only=True),
        client.get_lives_async()
    )

    print(f"Saison active : {saisons[0].libelle}")
    print(f"Matchs en direct : {len(lives)}")

asyncio.run(main())
FAQ

Questions Fréquentes

Tout ce que vous devez savoir sur le SDK et son utilisation.

Qu'est-ce que ffbb-data-client ? +

C'est le SDK Python moderne, asynchrone et typé (Pydantic v2) pour interagir avec les APIs publiques de la Fédération Française de BasketBall (FFBB). Il permet de manipuler calendriers, classements, statistiques et scores live avec une simplicité maximale.

Faut-il une clé d'API ou un compte ? +

Non. Le TokenManager intégré résout et renouvelle automatiquement les clés publiques nécessaires en toute transparence. Aucune configuration manuelle n'est requise.

Est-ce compatible avec FastAPI et async ? +

Oui, absolument. 100% des méthodes de la façade disposent d'un équivalent *_async() basé sur httpx, parfaitement adapté aux architectures asynchrones à fort trafic.

Quelle relation avec le Serveur MCP ? +

ffbb-data-client est la bibliothèque Python (SDK) d'accès aux données. FFBB MCP Server est le serveur de contexte IA (Model Context Protocol) qui expose ces données sous forme d'outils et de ressources pour les LLM (Claude, Cursor, Copilot).
